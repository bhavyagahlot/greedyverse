Single-Source Shortest Path

Dijkstra's Algorithm

Finds the absolute lowest-cost path from a starting vertex to all other vertices in non-negative weighted graphs. Operates by greedily finalizing the closest unvisited vertex at each step.

Time: O(V²) Space: O(V²) Constraint: Weights ≥ 0
Vertex-Centric MST

Prim's Algorithm

Grows a Minimum Spanning Tree outward from a root vertex by repeatedly choosing the cheapest edge that crosses the cut between the tree and remaining vertices.

Time: O(V²) Space: O(V²) Cut Property: Optimal
Edge-Centric + DSU

Kruskal's Algorithm

Sorts all graph edges globally by ascending weight, accepting edges that connect disjoint components while using Disjoint Set Union (DSU) to reject edges that form cycles.

Time: O(E log E) Space: O(E + V) DSU: Union-Find

What is a Greedy Algorithm?

Understanding the fundamental design paradigm that powers modern network routing and spanning tree construction.

🎯

1. Greedy-Choice Property

A globally optimal solution can be arrived at by making locally optimal (greedy) choices at each stage without reconsidering previous decisions.

🛠

2. Optimal Substructure

An optimal solution to the problem contains within it optimal solutions to subproblems, ensuring mathematical convergence to the global optimum.

⚖

3. No Backtracking

Unlike Dynamic Programming or Backtracking, Greedy algorithms commit irreversibly to their choices, yielding superior runtime efficiency.

Academic Analysis: When is Prim vs Kruskal Faster?

In academic algorithm analysis, neither algorithm is unconditionally "faster". Their efficiency depends primarily on the density of the graph:

MetricPrim's Algorithm (Adjacency Matrix)Kruskal's Algorithm (DSU)
Theoretical Complexity O(V²) O(E log E)
Sparse Graph Behavior (E ≪ V²) Matrix scan always takes O(V²) regardless of sparsity. Very fast! Sorting small number of edges takes minimal operations.
Dense Graph Behavior (E ≈ V²) Superior! Takes O(V²), avoiding expensive edge sorting. Slower, as sorting V² edges requires O(V² log V).
Cycle Detection Implicit via the Cut Property (never creates cycles). Explicit via Disjoint Set Union (Path Compression + Union by Rank).
